# PadnaKesht Telegram Store

فروشگاه تلگرامی پادناکِشت — «از دل طبیعت دنا»\n\n**سیاست ارسال:** ارسال به اصفهان و سایر شهرها رایگان است؛ مبلغ ارسال در سرور صفر محاسبه می‌شود.

این مخزن اکنون شامل رابط فروشگاه فارسی، API ثبت سفارش، پایگاه داده SQLite، کنترل دسترسی مدیر و تست پایه است.

## وضعیت واقعی
- رابط فروشگاه راست‌چین و واکنش‌گرا: آماده در کد
- API و ذخیره‌سازی SQLite: پیاده‌سازی شده
- اعتبارسنجی امضای Telegram Mini App initData سمت سرور: پیاده‌سازی شده
- ثبت سفارش، رزرو اتمیک موجودی، ثبت کد پیگیری پرداخت، مدیریت وضعیت: پیاده‌سازی شده
- تست خودکار GitHub Actions: موفق در اجرای شماره ۷
- میزبانی عمومی: هنوز مستقر نشده است
- اتصال منوی ربات به URL عمومی: هنوز انجام نشده است
- تنظیم اطلاعات واقعی کارت، شناسه مدیر و فهرست روزآمد کالاها: نیازمند تنظیم امن توسط مالک

## اجرای محلی
نیازمند Node.js 20 یا جدیدتر:
1. `cp .env.example .env`
2. مقدارهای لازم را در فایل محلی `.env` وارد کن؛ هرگز این فایل را commit نکن.
3. `npm install`
4. `npm run check`
5. `npm test`
6. `npm start`
7. باز کردن `http://localhost:3000`

ثبت سفارش واقعی فقط وقتی کار می‌کند که Mini App از داخل تلگرام باز شود و `BOT_TOKEN` به‌صورت محرمانه در سرور تنظیم شده باشد.

## متغیرهای محرمانه/عملیاتی
- `BOT_TOKEN`: توکن ربات
- `ADMIN_TELEGRAM_IDS`: شناسه عددی مدیر/مدیران، جداشده با کاما
- `CARD_HOLDER_NAME`: نام صاحب کارت
- `CARD_NUMBER`: شماره کارت
- `DATABASE_PATH`: مسیر SQLite روی دیسک دائمی

این مقدارها را فقط در بخش Secrets/Environment میزبان وارد کن؛ نه در مخزن عمومی و نه در گفت‌وگو.

## نکات مالی و امنیتی
- شماره کارت فقط در پاسخ مرحله ثبت سفارش/پرداخت ارسال می‌شود.
- ثبت کد پیگیری به‌خودی‌خود پرداخت را تأیید نمی‌کند.
- مبلغ نهایی از قیمت‌های ذخیره‌شده در سرور محاسبه می‌شود.
- موجودی هنگام ثبت سفارش به‌صورت تراکنشی رزرو و هنگام لغو پیش از ارسال بازگردانده می‌شود.
- برای سفارش لغوشده بعد از ارسال یا بازپرداخت بانکی، رسیدگی دستی لازم است.
