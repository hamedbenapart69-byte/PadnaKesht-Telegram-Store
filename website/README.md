# فروشگاه اینترنتی پادناکِشت

فروشگاه فارسی و راست‌چین پادناکِشت با فهرست محصولات، سبد خرید، ثبت درخواست سفارش، پیگیری سفارش و پنل مدیریت.

## نشانی انتشار

- فروشگاه: https://udvnmuxybqdquqoubflz.supabase.co/functions/v1/store-api/
- پنل مدیریت: https://udvnmuxybqdquqoubflz.supabase.co/functions/v1/store-api/?asset=admin.html
- اعتبار تصاویر: https://udvnmuxybqdquqoubflz.supabase.co/functions/v1/store-api/?asset=credits.html

## زیرساخت

- میزبانی رایگان فایل‌های سایت و API در Supabase Edge Function موجود با نام `store-api`
- پایگاه داده همان پروژه Supabase موجود؛ پروژه یا پلن پولی جدید ساخته نشده است
- GitHub برای نگهداری سورس، کنترل نسخه و آزمون‌های خودکار
- بدون Cloudflare، Render، سرویس پولی، اعتبار هوش مصنوعی یا درگاه پرداخت

فایل‌های عمومی سایت در سورس `website/public/` نگهداری می‌شوند و نسخهٔ همگام‌شدهٔ آن‌ها داخل `STATIC_ASSETS` در Edge Function قرار دارد. آزمون CI تطابق این دو نسخه را کنترل می‌کند.

## امکانات

- نمایش ۱۳ محصول فعال از پایگاه داده
- جست‌وجو/فیلتر دسته‌ها، سبد خرید و ثبت درخواست سفارش
- پیگیری سفارش با کد و شماره تماس
- پنل مدیر برای تأیید قیمت و موجودی، مدیریت سفارش‌ها و تغییر وضعیت
- رزرو تراکنشی موجودی هنگام تأیید سفارش و بازگرداندن آن هنگام لغو مجاز
- نشست مدیر با هش گذرواژه PBKDF2، امضای HMAC و محدودسازی تلاش‌ها

## راه‌اندازی مدیر

1. نشانی پنل مدیریت را باز کنید.
2. کد یک‌بارمصرفی را که در تحویل اولیه ارائه شده وارد کنید.
3. گذرواژه‌ای با حداقل ۱۲ نویسه بسازید.
4. کد راه‌اندازی پس از استفاده باطل می‌شود.

## قیمت، موجودی و سفارش

قیمت و موجودی فعلی ۱۳ محصول در پایگاه داده تأیید نشده است. تا وقتی مدیر مقدار واقعی روز را ثبت نکند، سایت قیمت و موجودی قطعی نشان نمی‌دهد؛ اما مشتری می‌تواند درخواست خرید را ثبت کند. مبلغ نهایی و هزینه ارسال پیش از تأیید سفارش با مشتری هماهنگ می‌شود.

پرداخت اینترنتی در این نسخه فعال نیست. ثبت درخواست به‌تنهایی به معنی تأیید سفارش یا دریافت وجه نیست.

## تصاویر

تصاویر فعلی از Pexels و صرفاً نمایشی‌اند؛ عکس اختصاصی کالاها، بسته‌بندی یا تولیدکنندگان پادناکِشت نیستند. این موضوع در خود فروشگاه و صفحهٔ اعتبار تصاویر اعلام شده است. دسترسی به دامنهٔ تصاویر Pexels از داخل ایران ممکن است به محدودیت شبکه وابسته باشد.

GitHub Actions شامل آزمون ساختار و همگام‌بودن فایل‌ها، بررسی TypeScript تابع Supabase و ۱۰ بازبینی مستقل معماری، امنیت، پایگاه داده، سفارش، موجودی، دسترس‌پذیری، واکنش‌گرایی، تصاویر، عملکرد و استقرار است. شاخه انتشار با موفقیت همهٔ آزمون‌ها به‌روزرسانی می‌شود.
