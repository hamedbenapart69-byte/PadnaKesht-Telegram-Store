# فروشگاه اینترنتی پادناکِشت

فروشگاه مستقل فارسی و راست‌چین با سبد خرید، ثبت درخواست سفارش، پیگیری سفارش و پنل مدیریت.

## زیرساخت
- Cloudflare Workers برای سایت و API
- Cloudflare D1 برای کالاها، سفارش‌ها و گزارش تغییر وضعیت
- بدون پرداخت آنلاین و بدون اتصال به سرویس ثالث
- بدون وابستگی به اعتبار روزانه ابزارهای هوش مصنوعی

## استقرار
در Cloudflare Dashboard از مسیر Workers & Pages یک Worker جدید بسازید و مخزن GitHub را به آن متصل کنید:
- Repository: `hamedbenapart69-byte/PadnaKesht-Telegram-Store`
- Branch: `website-storefront`
- Root directory: `website`
- Build command: خالی
- Deploy command: `npx wrangler deploy`

فایل `wrangler.toml` اتصال D1 را با نام `padnakasht-store-db` تعریف می‌کند. در اولین انتشار، Cloudflare می‌تواند D1 binding را خودکار ایجاد کند؛ وضعیت اتصال DB پس از استقرار باید در داشبورد بررسی شود.

## تنظیمات محرمانه
در Worker > Settings > Variables and Secrets دو مقدار از نوع Secret تعریف کنید:
- `ADMIN_PASSWORD`: گذرواژه قوی پنل مدیریت
- `ADMIN_SESSION_SECRET`: مقدار تصادفی محرمانه با حداقل ۳۲ نویسه

هیچ‌کدام را در GitHub یا فایل‌های این مخزن قرار ندهید.

## قیمت و موجودی
کالاها با قیمت و موجودی نامشخص آغاز می‌شوند تا قیمت‌های قدیمی به‌عنوان قیمت روز نمایش داده نشوند. مدیر باید قیمت و موجودی واقعی را در پنل ثبت کند. سفارش مشتری تا بررسی قیمت، موجودی و هزینه ارسال، «درخواست خرید» است و فروش قطعی محسوب نمی‌شود.

## محدودیت
پرداخت اینترنتی در این نسخه وجود ندارد. سفارش‌ها در پایگاه داده ذخیره می‌شوند و مدیر پس از بررسی، قیمت، هزینه ارسال و وضعیت را تأیید می‌کند.
